# 示例事件

证监会主席吴清在上市仪式上表示，这是内地与香港深化资本市场务实合作的又一重要里程碑，“正当其时，水到渠成”。媒体关注点如下：一是关注产品推出意义及作用。新华网报道，香港特区政府财政司司长陈茂波2日发表网志表示，这是香港离岸人民币业务枢纽发展的新里程，不仅丰富香港市场的人民币风险管理工具，更标志着国债在离岸市场的深化发展和人民币国际化的有序推进。新华财经报道，该产品的推出被视为补齐离岸人民币利率风险管理工具链的“重要一环”，将进一步增强人民币资产吸引力。业内人士认为，过去境外投资者主要依赖场外工具管理利率风险，5年期人民币国债期货的推出，将与现有的债券通、互换通共同构成“现券-互换-期货”三位一体的完整风险管理闭环。证券时报报道称，该产品作为离岸市场唯一的国债期货合约产品，旨在满足境外投资者日益增长的利率风险管理及交易需求。推出五年期国债期货是推动香港成为离岸人民币枢纽及风险管理中心的重要一步。二是关注合约设计区别。观点网报道称，根据香港证监会披露，首个上市的5年期国债期货将采用现金结算，价格按一篮子中国国债厘定，而在岸品种采用实物交割的方式。香港国债期货合约金额为50万元人民币，仅为在岸同期限品种的一半，其交易时间长于在岸市场。新华财经援引业内人士观点称，合约设计充分考虑了离岸市场的特点和境外投资者的交易习惯，更贴合离岸市场的需求。

此外，境外媒体方面，彭博社报道称，香港周一推出中国国债期货，合约规模50万元、现金结算，跟踪在岸尾盘交易。外资持有在岸国债已升至2万亿元，市场条件较此前成熟。该产品旨在提供关键对冲工具，助力债券市场开放和人民币国际化。做市商和套保需求有望支持初期流动性，但低收益率或限制交易兴趣，未来在岸与离岸市场联动料将加强。联合早报称，港交所推出国债期货，是继中国证监会今年4月24日起允许合格境外投资者参与国债期货交易以来，北京推动人民币国际化的又一里程碑。
